Your Data, Your Device

Absolute Privacy — By Design

Echoes was built on an uncompromising principle: your memories belong to you and no one else. Local Ollama AI runs on your device; no memories ever touch external cloud servers.

💻

Local Ollama AI

All AI processing (Qwen2.5 3B) occurs directly on your local hardware via Ollama. No OpenAI, Anthropic, or external API keys are ever used.

🗄

LocalStorage Only

All data — memories, ofrenda cards, conversations, stories — is stored in your browser's LocalStorage. It lives on your device and stays there.

💾

JSON Export & Import

Export your entire sanctuary to a clean JSON backup file at any time. Import it onto any browser or machine without vendor lock-in.

🛡

Graceful Offline Mode

When Ollama is not running, Echoes seamlessly switches to an embedded offline pattern generator. The app never breaks and never begs for cloud credentials.

👤

Zero Accounts

There is no registration, no login, no email address collected. Nothing to create. Nothing to give. Open Echoes and it's ready — just for you.

📊

Zero Analytics

There is no tracking, no analytics, no telemetry. Echoes does not know how you use it, who you are, or what you remember. Only you know that.

Sanctuary Data Management

Manage your sovereign memory vault. Create offline JSON backups, restore from an existing file, or revisit the setup guide.

Open-Source & Transparent

Echoes is built with open web standards and local open-source AI — no surveillance, no trackers, no secrets.

🦙 Local AI Setup Guide (Ollama)

Echoes uses Ollama to run open-source language models like Qwen2.5 3B locally on your machine. Follow these 3 easy steps to activate local AI:

1

Install Ollama

Download and install the free open-source Ollama runtime for your OS from ollama.ai/download.

2

Start Service & Pull Qwen2.5 3B

Open your terminal and run these commands (click any command to copy):

ollama serve Copy
ollama run qwen2.5:3b Copy
3

Start Echoes Server

In your project root, start the local server:

npm start Copy

The connection pill in the navbar will illuminate 🟢 green with Local: qwen2.5:3b.

☁

Using Echoes on Vercel?

On Vercel, the app runs out-of-the-box using the Built-in Offline Sanctuary Engine. To connect your laptop's local Ollama to the live Vercel deployment:

cloudflared tunnel --url http://localhost:11434 Copy

Or with ngrok: ngrok http 11434. Then paste the generated https://... tunnel URL into AI Settings → Ollama Host URL.

💡 Performance Tip: Qwen2.5 3B only requires ~2.5GB of RAM/VRAM and delivers excellent literary prose. If you have a larger GPU, you can also pull qwen2.5:7b or llama3.2 and select it in the AI Settings modal.
