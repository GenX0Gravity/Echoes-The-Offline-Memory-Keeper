## ✦ Problem Statement

In the modern digital age, human memories are fragmented across proprietary cloud platforms, corporate social feeds, and closed AI chatbots that exploit user data for advertising, model training, and algorithmic engagement. 

When memories are stored in traditional cloud services:
1. **Privacy is compromised**: Intimate reflections, personal grief, family stories, and vulnerability are transmitted to centralized servers and stored in cleartext or analyzed by closed APIs.
2. **Longevity is fragile**: Platforms sunset, accounts get locked, subscription tiers expire, and corporate terms change without user consent.
3. **Emotional resonance is lost**: Generic productivity dashboards and sterile note apps lack the sacred warmth, poetic depth, and ritual reverence needed for honoring lived experiences and departed loved ones.

### The Echoes Solution
**Echoes** creates an intimate, sovereign sanctuary where memories, reflections, and remembrances reside **exclusively on your physical device**. Powered by **local open-source AI (Ollama + Qwen2.5 3B)**, Echoes weaves your memories into timeless narratives, provides an empathetic conversational companion, and creates digital ofrenda altars with **zero cloud dependencies, zero corporate telemetry, and zero paid API keys**.

## 🌙 Features

### 1. 🗝 Memory Vault (Sovereign Storage)
- **Rich Memory Cards**: Capture title, narrative text, categories, emotional moods, and searchable tags.
- **Advanced Real-Time Filtering**: Instant search across titles, contents, and tags with debounced execution.
- **Mood & Category Management**: Filter by 8 emotional moods (`Nostalgic`, `Joyful`, `Peaceful`, `Mysterious`, `Bittersweet`, `Transformative`, `Sorrowful`, `Grateful`) and categories (`Moments`, `People`, `Places`, `Dreams`, `Stories`).
- **Flexible Sorting**: Sort by newest, oldest, alphabetical (A–Z), or mood grouping.
- **JSON Export & Import**: 1-click full backup download and schema-validated restore with merge/replace conflict resolution.

### 2. 📜 AI Storyteller (Qwen2.5 3B Powered)
- **Memory-to-Story Synthesis**: Converts brief, raw memory fragments into deeply moving, literary prose.
- **Vault Integration**: Select any saved memory directly from your vault or draft thoughts freeform.
- **4 Distinct Creative Tones**:
  - **❤️ Emotional**: Raw vulnerability, profound human connection, and heartfelt resonance.
  - **🌅 Nostalgic**: Warm sepia tones, golden hour light, and the gentle ache of passing seasons.
  - **🌸 Poetic**: Lyrical, metaphorical cadence draped in gothic elegance.
  - **📖 Storytelling**: Cinematic narrative arcs with poignant pacing and memorable resolution.
- **Model Attribution**: Live badges display whether the story was generated by local Ollama (`qwen2.5:3b`), a secure tunnel, or the embedded offline pattern engine.

### 3. 🌙 Memory Companion (Echo)
- **Context-Aware Dialogue**: An empathetic companion persona trained to facilitate memory preservation.
- **Thoughtful Follow-Up Excavation**: Echo asks gentle, targeted sensory questions (e.g. *“What did the light feel like in that moment?”*, *“What scent or sound from that day returns to you first?”*) to unearth forgotten details before they fade.
- **Companion Tone Control**: Adjust Echo's conversational style between Emotional, Nostalgic, Poetic, and Storytelling.
- **Multi-Turn Context**: Preserves conversational thread locally so Echo remembers details shared throughout your session.

### 4. 🕯 Digital Ofrenda (Altar of Light)
- **Remembrance Cards**: Dedicated to loved ones and ancestors, inspired by Día de los Muertos traditions.
- **Photo Uploads**: Client-side photo processing stored safely as Base64 in LocalStorage.
- **AI Remembrance Inscriptions**: One-click AI dedication generator that composes heartfelt epitaphs based on the person's name, dates, beloved items, and chosen tone.
- **Candlelight Atmosphere**: Animated flickering flames and warm radial illumination.

### 5. 👻 Ghost Mode (Atmospheric Shift)
- **Veil-Thinning Visuals**: Enhances particle count (2x density) with ascending purple wisps and radiant gothic lighting.
- **Messages From Beyond**: Philosophical cards meditating on memory, continuity, and love across time.
- **Spectral Orb Activation**: Interactive glowing orb toggle.

### 6. 🎤 Voice Dictation (Web Speech API)
- **Hands-Free Dictation**: Integrated microphone buttons in the Memory Form, AI Storyteller, and Memory Companion.
- **Local Browser Speech**: Utilizes native browser speech recognition without sending audio streams to third-party transcription services.
- **Pulsing Visual Indicator**: Subtle ember pulse animations while listening.

### 7. 🔔 Ambient Audio Synthesizer (Web Audio API)
- **Harmonic Chimes**: Zero audio file dependencies; synthesizes soothing 432Hz harmonic chimes and candle strike frequencies directly via the browser's `AudioContext`.
- **Toggleable**: Easily muted or activated from the top navigation bar.

### 8. ✨ Interactive Onboarding Tour
- **First-Time Guided Journey**: A welcoming 4-step walkthrough introducing the sanctuary's philosophy, spaces, local AI setup, and data sovereignty.
- **Revisitable**: Can be relaunched at any time from the navigation bar or Privacy settings.

## 🏛 Architecture & Data Flow

Echoes maintains an air-gapped data architecture: your memories never touch public corporate AI services.

```mermaid
graph TD
    subgraph Browser Client (Frontend)
        UI[Vanilla HTML5/CSS3 Interface]
        Speech[Web Speech API Dictation]
        Audio[Web Audio Synthesizer]
        Canvas[Canvas Particle System]
        Store[(Browser LocalStorage)]
        AI_Client[Client AI Manager & Hybrid Engine]
    end

    subgraph Local Runtime (Local Node Server)
        Express[Express Server :3000]
        LocalPrompts[Prompt Engineering Engine]
    end

    subgraph Cloud Runtime (Vercel Serverless)
        VercelAPI[Vercel Serverless API /api/*]
    end

    subgraph User Local AI Environment (Ollama)
        OllamaDaemon[Ollama Service :11434]
        Qwen[Qwen2.5 3B Model Weights]
        Tunnel[Optional Cloudflare / ngrok Tunnel]
    end

    UI <--> Store
    Speech --> UI
    UI --> Audio
    Canvas --> UI

    UI <--> AI_Client
    
    %% Local Path
    AI_Client -- Local Dev: REST --> Express
    Express <--> LocalPrompts
    Express -- Loopback 127.0.0.1:11434 --> OllamaDaemon
    
    %% Cloud / Vercel Path
    AI_Client -- Vercel Deployment: REST --> VercelAPI
    VercelAPI -. Optional Secure Tunnel .-> Tunnel
    Tunnel -. Forward .-> OllamaDaemon
    
    OllamaDaemon <--> Qwen
    
    %% Fallback
    AI_Client -. Zero Config Cloud / Offline Mode .-> Store
```

## 🚀 Local Installation Guide

### Step 1: Clone the Repository
```bash
git clone https://github.com/<your-username>/Echoes-The-Offline-Memory-Keeper.git
cd Echoes-The-Offline-Memory-Keeper
```

### Step 2: Install Dependencies
```bash
npm install
```

### Step 3: Set Up Ollama & Qwen2.5 3B
Echoes is optimized for [Ollama](https://ollama.ai/download) running locally:

#### Windows
1. Download and run the installer from [ollama.ai/download](https://ollama.ai/download).
2. Open PowerShell or Command Prompt:
   ```powershell
   ollama serve
   ollama run qwen2.5:3b
   ```

#### macOS
1. Install via Homebrew or DMG:
   ```bash
   brew install ollama
   ollama serve
   ollama run qwen2.5:3b
   ```

#### Linux
1. Install Ollama:
   ```bash
   curl -fsSL https://ollama.com/install.sh | sh
   ollama serve
   ollama run qwen2.5:3b
   ```

*(Note: Echoes includes an embedded offline memory engine. If Ollama is not currently active, the application automatically falls back to offline mode and remains 100% functional!)*

### Step 4: Start the Echoes Server
```bash
npm start
```
Open **http://localhost:3000** in your browser. The status pill will light up 🟢 **Local: qwen2.5:3b**.

## ☁ Deploying to Vercel

Echoes is engineered for zero-friction Vercel deployment:

### Quick Deploy via Vercel CLI
```bash
npm i -g vercel
vercel
```

### Deploy via GitHub Repository
1. Push your repository to GitHub.
2. Log into [vercel.com](https://vercel.com) and click **"Add New Project"**.
3. Import your `Echoes-The-Offline-Memory-Keeper` repository.
4. Keep the default settings (Framework Preset: **Other**, Build Command: `npm run build`, Output Directory: `./`).
5. Click **Deploy**.

### Understanding AI on Vercel
Because Vercel serverless functions run in the cloud, they do not have direct access to your personal computer's `127.0.0.1` loopback. Echoes handles this with complete transparency and flexibility:

1. **Out-of-the-Box (Offline Mode)**:
   The app works immediately on your Vercel deployment without any setup! All features (Vault, Storyteller, Companion, Ofrenda, Ghost Mode) utilize the rich **Built-in Offline Sanctuary Engine**.
2. **Connecting your Local Ollama to Vercel (Optional)**:
   If you want the live Vercel deployment to communicate with your machine's local Ollama instance:
   ```bash
   # Option A: Cloudflare Tunnel (Free, no account required)
   cloudflared tunnel --url http://localhost:11434

   # Option B: ngrok (Free)
   ngrok http 11434
   ```
   Copy the generated HTTPS URL (e.g., `https://random-words.trycloudflare.com`), open your deployed Vercel site, click **AI Settings**, paste the URL into **Ollama Host URL**, and click **Save Configuration**. The pill turns 🟡 **Tunnel: qwen2.5:3b**!

## 🧠 How Open-Source AI Powers Echoes

### 1. High-Literacy, Zero-Cost Inference (Qwen2.5 3B)
Qwen2.5 3B was selected as the default model because it punches far above its parameter size in creative writing, emotional depth, and sensory vocabulary while requiring only ~2.5GB of RAM. It runs smoothly on standard laptops without dedicated GPUs.

### 2. Prompt Engineering Guardrails
Prompts are isolated into modular templates in [`server/prompts.js`](file:///c:/MyProjects/Echoes/Echoes-The-Offline-Memory-Keeper/server/prompts.js):
- **Storyteller**: Instructs the model to treat the memory as a sacred artifact suspended in amber, grounding the narrative in sensory textures (scents, sounds, ambient lighting) without breaking character.
- **Companion (Echo)**: Enforces empathetic validation followed by 1–2 thoughtful excavation questions, preventing overwhelming questionnaires.
- **Ofrenda Dedicated Inscriptions**: Formulates respectful, touching tributes adhering to the Día de los Muertos spirit of remembrance.

### 3. Dynamic Model Switching
Through the in-app AI settings modal, users can inspect all models installed on their machine and switch dynamically to `llama3.2`, `mistral`, `gemma2`, or larger parameter models like `qwen2.5:7b` without restarting the server.
